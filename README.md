Para que el proyecto funcione se tiene que clonar directamente en la carpeta de htdocs localizada en la carpeta de instalacion del XAMPP del dispositivo, mover el script de la base de datos llamada svis_database.sql 
a esta misma carpeta (htdocs).

Ademas de esto se debera de mover el archivo svis-api.war ubicado en backend-java-maven/target/ a la carpeta de xampp/tomcat/webapps.

Por ultimo importar la base de datos a phpMyAdmin con el mismo nombre del archivo, ademas de ejecutar el archivo backend-java-maven desde un IDE especializado para java.
